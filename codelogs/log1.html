What are two (or more) benefits of using semantic tags?

There are several benefits to using semantic tags over not using them. For one thing, it makes the website easier to read both by computers and programmers alike. Trying to read the different div tags that you would need to have a HTML page without semantic tags would get messy really fast. It wouldn't be impossible to read, but it would certainly make it harder to read. Semantic tags by contrast make the website easy to read and follow along with. Another benefit of using semantic tags is that it is more accessible. Screen readers and other assistive technologies find it much easier to read semantic tags rather than non-semantic tags.
